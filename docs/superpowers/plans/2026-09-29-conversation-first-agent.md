# 流萤：以连续对话为核心的 Agent 改造计划

日期：2026-09-29，更新至 2026-10-17。状态：会话基础、一次真实追问与新会话隔离已验收；三轮连续追问及重启续聊尚待验收。流式、按需 RAG、自动记忆和第三方插件未交付。第 9 节保留历史记录，不作为最新完成声明。

## 本轮调整：自然聊天、自主记忆与插件（2026-10-17）

用户确认 MCP 和技能包两种都要，先实现 MCP。保留现有技术栈和数据，不继续把计费精度当作核心前置条件。

1. **聊天减负，先交付独立小批次**：成功回答不再逐条显示“已完成”、费用、token 和通用免责声明；来源折叠，必要的处理中、失败、恢复与授权仍明确可见。费用移入设置的“账单与用量”，通用规则移入“用户须知”。第一批复用当前本机只读接口，明确仅有当前会话最近 10 条，不冒充完整账单、实时余额或供应商扣款；下一批补当前身份下跨会话分页账本。撤回的数据不能在新入口重新出现。
2. **完成会话主链路**：按 P1/P2 补三轮追问、重启续聊、可撤销的持续在线授权与真实流式。当前单次授权不因界面精简自动扩大；未获得持续授权前仍显示本次内容预览与确认。
3. **自主长期记忆优先落地**：沿用 P4 的本机权威存储和模型工具协议，先接 memory.search / upsert；由 Agent 判断何时调用，不要求每次手选。自动记忆需单独开启，可管理、更正、删除、关闭和撤销；回答旁只给简短保存反馈，不堆砌版本和审计说明。失败不得宣称记住，删除不得被旧上下文自动复活。与按需 knowledge.search 共用工具调度，不把资料内容升级成用户指令。
4. **MCP 插件先行**：设置中添加远程服务、发现工具、查看数据访问及副作用、选择工具授权、启停和移除。首版范围为 HTTPS 远程工具服务，不在手机执行任意安装脚本或 stdio 程序。用户批准安装和工具范围后，Agent 可自主选择已允许的工具；写入、删除、对外发送等副作用单独确认。端点、工具 schema 或权限变化后重新核对；停用立即阻止后续调用，进行中的外部副作用不能谎称撤销。
5. **技能包第二阶段**：MCP 完整验收后，再做可查看来源、版本、所需工具和权限的技能包安装／禁用／卸载。技能文本不自动授予权限，不可自行安装代码、读取秘密或提升已有工具权限；本期不承诺任意第三方代码兼容。

MCP 工程约束：服务凭据走私密配置，不进入模型上下文、聊天、日志和导出；服务端发起请求时检查目标地址及重定向，拒绝私网、回环和云元数据地址，防止 SSRF。工具名按服务命名空间隔离，输入按 schema 校验，输出限制大小／时间并作为不可信数据；工具注解不能自行证明安全。支持工具列表分页，列表变化需重新核对已授权工具，不自动扩大授权。调用有次数／时间上限和可见的简短状态，不展示模型内部推理。此处是项目设计选择，不是声称协议自动提供这些保护。

协议依据：[MCP 工具规范](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)、[MCP 安全实践](https://modelcontextprotocol.io/docs/2025-11-25/tutorials/security/security_best_practices)。首版实现前再核对 transport / authorization 与运行环境兼容性。

## 1. 目标与优先级

用户希望流萤能自然连续聊天、自主选择工具、自主维护长期记忆，而不是每句话都提交一次工单。本计划优先于旧工程计划中与此冲突的交互排期；不撤销已有隐私边界和数据保留要求。

成功体验：打开即聊、追问接得上、答案逐步出现；需要资料时检索，需要已授权的跑步摘要时调用工具；重要偏好可以记住、查看、更正和删除。

不承诺与其他产品完全同等的能力或速度。先测量并修复实际延迟，不用流式动画掩盖失败。

## 3. 保留与收敛

保留 Android、现有前端、Worker / DO / D1、已有身份认证及任务幂等机制，不换技术栈。保持已通过真机确认的菜单、贴底输入框、圆角外观。

保留跑步记录、手环协议、运动状态机、离线流萤语音、Fish 播报与音乐压低逻辑，不把聊天改造混入运动控制。

费用仅估算展示和记账，不因超出预算关闭功能；不增加精密计费、向量数据库、通用文件系统工具、多 Agent 编排或新的云产品作为前置条件。

## 4. 目标链路与协议

手机会话 → 已认证的会话执行入口 → 按需读取上下文 → 模型决定直接回答或调用工具 → 流式回答 → 保存结果、按策略维护记忆。

- 增加 conversationId、turnId，复用现有 requestId 去重；按会话隔离上下文，不混入其他会话。
- 一个会话同一时间执行一个回合。重复点击、切后台、断网恢复不得新建重复模型请求。
- 先以有限最近回合实现上下文；接近上下文上限再生成带覆盖范围的摘要。摘要不是长期记忆，不能提升旧内容的指令权限。
- 使用独立的会话协议版本兼容旧任务、旧回执和旧 App，不直接把旧历史任务当作同一会话。
- 流事件包含 turnId、单调序号及 started / tool_started / tool_finished / text_delta / completed / failed；只暴露简短行动状态，不输出内部思考。
- 首选 HTTP 流式传输，经原生 Bridge 事件传给前端；具体平台适配先做本地窄链路验证。客户端重连查询原任务／续读已有结果，禁止重新生成。
- 部分文本标为未完成；失败不伪装成完整回答。最终消息只落一条，乱序和重复事件不能造成重复拼接。

## 5. 权限与自动记忆

### 一次说明，日常不反复打断

首次开启在线聊天时清楚说明发送聊天内容给模型；随后点击发送即执行。已有“单次授权”不能自动升级成长期授权。

跑步摘要访问、自动记忆分别设可撤销的持久开关。扩大到轨迹、连续心率、其他敏感数据仍需新授权。删除跑步记录、修改运动设置、对外发送等行为不纳入本期自主工具。

### 模型工具

- knowledge.search：模型按需检索官方角色／健康资料；返回来源、时效与剧透标记，默认防剧透。无结果时说明限制，普通聊天不被知识库无匹配拦截。
- runs.list / runs.summary：只访问已授权范围，不默认上传全部历史数据。
- memory.search / memory.upsert：开启自动记忆后，模型可保存用户明确表达的偏好、目标和稳定事实，并返回“已记住”轻提示及撤销入口。
- 记忆工具调用在本轮回答后也必须有明确状态；失败不宣称保存成功，也不使已生成回答丢失。

### 记忆文档实现

沿用本机记忆库作为第一阶段权威存储；通过应用受控工具执行读写，模型不能指定任意磁盘路径。文档视图与 Markdown 导出由同一份结构化记录生成，不维护第二套容易失配的独立文件。

字段包含内容、类别、来源回合、创建／更新时间、版本、有效状态。支持查看、手动修改、删除、自动更新历史和撤销；旧版本与并发编辑冲突不得静默覆盖用户修改。

初期只自动记用户明确表达的信息；不保存密钥、令牌、精确位置或推断的疾病，不把模型回答、RAG 文档指令、角色设定当成用户事实。检索内容不能诱导写记忆。被删除的记忆不能通过旧缓存／会话摘要自动复活；明确重新要求记住时才重新建立。

云端需要写本机记忆时，生成带唯一工具调用 ID 的操作，由原生权限执行器校验和幂等执行，再反馈结果。手机离线时不得假装已持久化；本期不增加云端长期记忆副本。

## 7. 速度验收

分开记录手机发出→云接收、模型首段、工具耗时、整段完成、手机展示；同机耗时用单调时钟，跨设备时间戳只作辅助。

工程目标而非已达成承诺：发送后 300ms 内出现本机状态；稳定网络下普通短问答首段目标 5 秒内、完整回答目标 15 秒内。工具问题单列，不与纯闲聊混算；网络不可达要明确报错，不能无限等待。

先本地假模型验证，再经用户许可做少量真实问答测量。记录每次网络条件和各阶段耗时；小样本不冒充可靠 P95。未达目标以观测瓶颈调整，不擅自换供应商、购买套餐或扩大付费测试。

## 8. 发布、回退与配合

- 每阶段更新进度与测试证据，分模块检查差异。已有 213 项工作区改动是当前快照计数，不是本计划产出。
- 协议和迁移先兼容旧版本，使用受控开关切换新会话链路。回退代码仍保留新数据；不执行破坏性数据库降级。

- 生产发布、真实模型调用、扩大数据权限及记忆开关启用前说明范围。需要用户配合时集中提出，不逐条弹出不必要的确认。
- 本次批准规划不等于已启用持久云处理／自动记忆权限。开发可先用合成数据完成。
