# 精选双库第一批：检索与回答上下文

用户要求继续开发，沿用长期记忆与 RAG 优先方向。本批仅本地实现与验证，不读取私密配置、不部署、不调用真实模型、不改手机。

1. 实现纯文本精选资料索引：健康与流萤分库，保留来源、版本、发布时间、核验时间、有效期、撤回和剧透标记。验证中文检索、切片、来源白名单、无结果和不可用状态。
2. 以显式可信选项接入 `runAgent`：先检索后回答，不新增工具或模型轮次；资料只进 user 数据，不进 system。健康库不能返回角色资料。检索无结果不请求模型；正常答案由程序附上“本次检索来源（不代表逐条采用）”，不让模型生成来源列表。验证旧路径完全不变、注入不授予跑步权限、最终答案大小仍符合原协议。
3. 添加一份已核对 WHO 官方页面的人工摘要和本地演示命令；流萤库在官方正文获取成功前保持空，不把测试夹具当真实角色资料。验证 Node／Workers 类型、现有全量回归与本地 workerd。

范围限制：不在生产服务、DO、HTTP、手机或前端自动启用。下一批须补角色官方语料、页面库选择与来源展示、授权模式下的服务接线；自动日更后置。现有密钥上传和真实请求仍待明确授权。本批可选知识库配置由可信调用方提供，不接受客户端提交索引或任意来源 URL。

检索采用有上限的小语料逐段词项匹配（中文双字片段、英文单词），不声称语义理解、医学证据分级、矛盾消解或全面覆盖；不使用嵌入/向量服务。程序能保证给出的来源来自索引，但不能单靠提示词保证模型逐句有据，因此来源附录明确表示“提供给模型”，真实回答质量仍需后续评测。
