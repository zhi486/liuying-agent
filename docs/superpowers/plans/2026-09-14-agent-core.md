# M1A：有界 Agent 核心实施计划

> 执行方式：主代理直接实施；独立只读复审。按执行计划与测试驱动技能逐项验证，不自动提交、推送或部署。

**目标：** 在本仓库新增可离线测试的真实模型—工具循环核心。真实供应商、HTTP 服务、持久任务与手机界面尚不在此批完成范围。

**架构：** `agent-server` 独立 TypeScript 包；模型与额度账本通过必需端口注入，默认不提供可绕过预算的生产适配器。只读工具直接执行在经过验证的授权摘要快照上。无运行时第三方依赖、无付费请求、无隐式网络。

**技术栈：** Node 22.22.2、pnpm 11.19.0、TypeScript 5.9.2、Node 内置测试运行器与类型擦除。核心只用 Web 标准 API，便于后续接 Workers。

**依据：** [总体设计](../specs/2026-09-14-liuying-agent-design.md)、[工程计划书](2026-09-14-liuying-agent-program.md)。不触碰现有未提交业务修改。

## Task 4：时间、取消与预算门禁

- [x] 测试先覆盖：预算拒绝不调用模型、预留在调用前、成功按用量结算、异常/取消保留不确定费用、已取消不工作、永不返回的模型超时、结算失败停止后续调用。
- [x] 默认单任务 30 秒，可由可信调用方缩短；排队层以后必须传剩余时间，禁止用户或模型扩大上限。
- [x] 必需 `BudgetPort`：按 `taskId/step` 预留、以 `usage` / `uncertain` / `not_dispatched` 结算；生产端口必须持久、事务、幂等，`uncertain` 保留额度不可视为免费。
- [x] 模型端口必须遵守已预留的输入/输出 token 上限并上报用量。费用端口只在测试使用内存替身，本阶段不声称有生产预算账本。
- [x] 整体截止时间包含额度端口等待；取消后不启动新调用。晚到的预留应释放未发送费用，已经发送但用量未知的请求须保留额度。
