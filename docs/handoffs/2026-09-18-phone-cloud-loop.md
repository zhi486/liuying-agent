# 手机单次授权、发送与回答展示

日期：2026-09-18。承接用户“补齐手机端的单次授权、发送和回答展示”。主代理直接实现，子代理只读审查；没有扩展计费、RAG 或自动记忆提取。

## 本轮交付

- 首页“在线执行”不再永久禁用；未配置时保持禁用。原生私密窗口独立填写 HTTPS origin、ownerId、deviceId 和云端签发的设备 Bearer，不使用语音开关或 DeepSeek/Fish 供应商密钥。
- 配置保存不联网；凭据沿用 Android Keystore AES-GCM 与 noBackup 存储。配置窗口禁止截图、自动填充及状态回填，关闭清空；同值保存幂等，损坏旧配置可重新导入。真正更换身份/凭据代次后，入口只显示新配置记录，旧记录仍在原身份下，不转发。
- `cloud.prepare` 在原生绑定身份、问题、所选记忆 ID/版本及当前正文；前端完整展示再点“同意本次上传并发送”。准备不落在线意图、不发网；取消不发网；准备最多两分钟有效，重载或退到后台失效。
- `cloud.confirm` 消费单次令牌，再次事务核对记忆，持久化新在线意图。Room v4→v5 只增 `memoryRefsJson`；旧 `prompt_only_v1` 不扩义，含记忆的新授权为 `selected_memories_v1`。只保存引用，不另存记忆正文副本。
- 实际派发时再次在同一事务核对记忆版本、删除状态、归属和来源，并占用唯一 POST 许可。进程重启、断网、404 均不补发原 POST；只显式恢复同一键查询。
- 应用级有界协程执行，Bridge 不等待长 HTTP；Web 两秒刷新仅查询本机。正常执行中有界查询云回执，网络错误停止；最长两分钟结束本轮操作，后续用户可恢复查询。
- 回答落盘后再 acknowledge；页面纯文本显示并保留重载后的回答。授权记忆 ID/版本可展开，不声称模型全部采用。取消/撤回先落盘，撤回立即隐藏本机回答，云端确认单独显示；已有 HTTP 尾段遇到撤回也不会漏发后续控制。
- 最近列表最多 10 条，完整记录按实际 JSON 字节预算限制为 220000 字节；极端控制字符转义也不突破 256 KiB Bridge 上限。不截断单条回答。本轮没有全历史在线分页或跨配置历史切换界面。
- 原“仅保存”仍只存文字、不会附带记忆；已有本机任务绝不自动上传。不改跑步/B5/语音链路。
