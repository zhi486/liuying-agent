## 计数工具的可信边界

固定模型来源 commit `dba1be0a40aa45a94ad051997016db3960a90277`，编码参考 SHA-256 `502bdaec8a3fd88ebc24c4721a7038fbe42f2063c664638127056107920035c1`，词表 SHA-256 `c90dfa01249db1be4245780a052ede752e1361c612ac6d08e2bdada7d599476b`。源文件先完整审阅，再下载校验；不运行 `trust_remote_code`，不下载模型权重。原 MIT 许可证已保留。

Windows 工具环境位于该目录 `.venv`，固定 `tokenizers 0.23.2` 带哈希 wheel，使用 `--no-deps`；只执行本地文件编码，不依赖联网加载的 Hub 功能。`.assets`、`.venv` 均被工具自己的 `.gitignore` 忽略，不改系统 Python 或后端依赖。

当前只支持已明确的纯文本非思考请求、两个工具和完整调用历史；未知协议字段拒绝，不静默遗漏后宣称合格。测试中的空文本/特殊角色标记是编码边界样本，不代表生产允许空用户任务。

固定对照由独立调用官方参考取得，不由被测 `count_request` 在测试中自算预期。对照 token 数、prompt 哈希和按 little-endian uint32 编码的 token IDs 哈希。三轮虚构请求通过真实 TypeScript 适配器导出，但 system 仅为短测试文案，数字不代表实际生产上下文。输出 `assurance=local_reference_only`，不返回提示词或 token IDs。

运行方法见 [工具说明](../../agent-server/tools/token-count/README.md)。计数工具不读取或发送密钥；未知错误只输出静态说明。

## Free 适配语义

保留 `recoverExecutions` 原先最多 100 条的通用接口，新 Free 入口强制 5 条。最坏计算为首页查询 1 条 + 每记录 8 条，共 41；按 batch 内部 SQL 语句计数，不依赖尚未明确的云端 batch 额度口径。**一次 invocation 只允许一个恢复页**，游标由后续调用继续；其他认证/清理/游标查询必须另计。

新增 `WaitUntil` 类型和保活副本工具，宿主通过私密 `run` 提供请求级回调，不在服务工厂保存 `ctx`。覆盖：

- Loop 取消后等待晚到预留并安全释放的完整链。
- Loop 已开始但可能超出结果等待期限的结算链。
- DeepSeek 的原始 operation，包括已经取得有效 usage 后的收据/结算。
- 服务原始 operation，包括迟到 claim/finish 回包。

宿主仍要注册外层 `run()`，具体示例见 [后端 README](../../agent-server/README.md)。保活副本仅返回 void 并消费原始错误，不能将其完成解释为收费成功；任务原链继续处理真实错误。宿主拒绝注册时返回静态错误，不继续发 HTTP；保活不是队列，不突破原截止、平台生命周期或额度。

新增/加强的测试检查宿主确实持有未完成 Promise，而非只在 Node 中等待一个 `setImmediate` 就假设云端也能存活。包括取消后收据仍记账 78 微美元、结果保持 withdrawn、超时后迟到认领不发模型请求、共享服务不串用请求回调。另验证宿主回调抛出时无 HTTP、无未处理拒绝。

## 验证过程与审查

先跑失败测试：计数模块缺失、Free 入口缺失，以及取消后宿主缺少保活链均被测试暴露；最小实现后转绿。此批后端原 154 项全部保留，新增 7 项并加强 5 个原测试；工具 16 项另计，7 组 golden 另计。

计数工具独立审查无 Critical/Important；坏资源哈希、golden 三字段篡改、A→B→A 缓存隔离的建议已固化测试。Free 复审发现两个 P2：预先取消且宿主注册抛错产生未处理拒绝；服务注册失败后等待终态回读期间仍可派发 HTTP。分别以失败回归证实，再通过提前消费取消拒绝、回读前立即 abort 修复；三项专项转绿。子代理独立复跑相关五个测试文件 68/68 通过，两个 P2 均关闭，无剩余 Critical/Important。本地阶段审查通过，不代表真云验收。

收尾验证：格式化后再次通过 161 项后端测试、16 项 Python 测试和 7 组固定对照；本批 Prettier 检查、包含未跟踪文件的空白检查通过，工具资源和隔离依赖被 Git 忽略。HEAD 仍为 `b2cdb7d70b7ee06c2982f34738a59c869ed6c634`，原有 Android/前端脏修改保留。

## 尚未完成 / 不应误报

1. 这是本地参考工具，不是 Workers 的生产计数器。JS/WASM 移植、Workers 实际类型、冷启动/CPU/内存仍未验收。
2. 没有创建云资源；正常三轮流程原有 41 次 D1 API 调用 / 76 条 SQL 未做降低或真云 batch 计量。Free 恢复页适配不等于整个 Agent 请求满足免费额度。
3. 没有真实 API `usage.prompt_tokens` 对照。线上隐藏模板、别名变化、特殊标记等仍需经授权核验，不能承诺“生产精确”。
4. HTTP 接口、手机云端闭环、实际 Cron/告警和供应商账单对账未建设；旧本机任务不自动上传。
5. 免费托管不等于 DeepSeek/Fish 免费，手机直连入口仍在后端账本以外，不能保证全 App $2 封顶。

建议下一步先评估生产计数器的可移植路径和 Workers 类型；真实云探针与小额供应商调用分别申请授权。不能为降低 SQL 去掉权限检查，也不能自动升级付费套餐。
