## 用户最终确认的界面方向

1. 参考 DeepSeek 手机端：主界面以对话、消息和输入框为中心，不在首页堆管理按钮与状态卡片。低频功能集中到账户详情。
2. “对话／跑步”不再使用醒目的底部双按钮，改为右上角小切换按钮。语音输入以图标呈现；输入与对话布局保持克制。
3. 默认白底，绿色参考 QQ 音乐图标中的青绿色，不使用刺眼的荧光绿或此前尝试的苔绿。当前白天主题主操作色 `#147a58`，点缀色 `#20c58a`；保留手动夜间主题。
4. 跑步页保持运动时易读；跑后总结包含分段及约每 5 秒的配速／心率图和区间展示。界面可借鉴 Keep 的信息层级，但不加入广告页面。
5. 单次在线执行授权、知识库与剧透许可、记忆选择等原有安全边界不因界面收纳而取消。语音识别只回填可编辑草稿，不自动发送 Agent 任务。
