# 单条跑步摘要接入在线 Agent

日期：2026-09-29。用户要求保留已在其他对话定稿的前端，继续功能开发。本批补齐手机原先固定发送空 `summaries` 的缺口，不重做视觉设计。

## 本批功能

- 跑后总结增加“让流萤复盘本次跑步”，仅将一条记录 ID 带到对话页并填入可编辑问题。不联网、不自动发送；可移除摘要。
- 导航选择只消费一次；发送成功或仅保存本机后清空本次选择，刷新／返回不重新附带旧记录。默认从首页进入时仍不含跑步数据。
- `cloud.prepare` 可选 `runId`，Web 不允许传指标或原始轨迹。原生从概要表读取已结束记录，只提取 ID、距离、用时、平均配速、平均心率；没有值保持 null，非法指标或未结束记录拒绝。
- 授权窗口展示原生读出的精确概要，并与所选 ID 核对；旧原生忽略字段或回错记录时拒绝，不偷偷降级成纯文字发送。确认前再查记录，变更／删除则失败；准备或放弃授权均不保存任务、不发网。
- 确认后的概要作为本次授权快照持久化。后续修改原记录不会改写已授权任务；这不是隐式同步或长期自动上传授权。组合记忆时仍在发送前执行原有版本核对。
- Room 6→7 只为 `agent_cloud_intents` 增加可空 `runSummaryJson` 列，原记录默认 NULL，旧请求正文／权限不变。已有记忆、任务、回答不做破坏性重建。
- 新授权版本 `selected_run_v1`，复用后端原有 `consent.runSummaries`、`summaries` 与 `runs.list`／`runs.summary`。本批不改后端运行时代码；共享合成请求位于 `contracts/agent/selected-run-request.json`，原生和后端同时验证。
- 历史回答的详情可查看本次授权摘要；撤回后隐藏摘要。确认后本机快照仍保留用于原任务恢复，不声称撤回能删除供应商已经收到的内容。

## 范围边界

不上传日期、GPS、地点、分段、连续心率或全量历史；自由文本仍可能含用户主动输入的隐私。只有单条复盘，不宣称已实现跨多次训练分析、自动计划写入或完整跑步周期。

继承新版前端样式、配色和导航，仅接入必要按钮／授权摘要；未将远端主分支合并进脏工作区，也未改跑中 BLE、GPS、确定性提醒或 Fish 播报。
