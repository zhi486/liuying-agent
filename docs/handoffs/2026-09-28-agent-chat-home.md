# 流萤对话首页简化交接

日期：2026-09-28。用户将前端方向修正为“参考 DeepSeek 手机端”：首页以对话和输入为中心，不堆管理按钮；低频操作进入账户详情。此方向优先于 2026-09-25 四栏导航、首屏可见资料卡片方案。

## 本轮实现

- 对话页上方为消息内容、下方为输入区；空态使用简短欢迎语。语音输入、仅保存、在线执行保留在输入区，资料与本次记忆选择折叠在“本次参考”。
- 底部导航由四项改为“对话／跑步”两项。账户详情由对话页右上角进入，集中在线 Agent 配置、本机任务及前往长期记忆、跑步记录、运动与语音设置的入口。
- 在线回答按用户消息／流萤回答呈现；费用和恢复／撤回操作默认折叠。本次授权仍须确认，已选择记忆、知识库和剧透许可的核对逻辑不变；语音识别仍只填草稿，不自动发送。
- 没有增加依赖、改动后端或改变 Cloudflare/Fish/阿里云配置。没有安装手机、部署云端或发起收费请求。

## 本地验证

- ESLint、Prettier、TypeScript、前端单测 227/227、Vite 生产构建与 bundle 校验均通过。
- 用本机 Chrome 在 390×844 视口检查对话空态和账户详情；截图位于 `frontend/build/ui-redesign/agent-minimal-viewport.png` 和 `agent-account-viewport.png`。浏览器无 Android Bridge，在线/语音按钮禁用是预期状态。
- 下一步：真机安装新版后，让用户按自己的使用习惯验收首页对话、账户详情、跑步跳转和一次授权前后的布局；本轮未进行真机测试。
