# 首页：“仅保存／在线执行”分流

日期：2026-09-17。用户本轮明确要求首页区分两个入口。本批完成界面分流，不将整个 S5 或真实在线执行标为完成。主代理直接实现，独立只读审查通过。

## 本批行为

| 入口 | 实际行为 |
| --- | --- |
| 仅保存 | 继续原有 `agent.submit` 本机 Room 路径，明确“不调用模型”，不会上传或执行 |
| 在线执行 | 明确标注“尚未开放”，按钮真实禁用且没有事件处理，不伪造网络／凭据故障，也不降级保存 |
| 上传说明 | 原生 details/summary 可鼠标、触屏或键盘开合；说明未来逐次确认、只发本次输入、可能消耗额度，以及输入内个人信息／秘密风险 |
| 本机详情 | 明确“未上传，也未执行”；今后接通云端仍不会自动提交 |

保留原有明暗主题、首页输入优先布局、两按钮至少 44px 触控高度。查看说明不改草稿、不发原生命令或网络请求；浏览器无 Bridge 时本机按钮仍禁用，但说明可读。未来上传边界是本次文字，不自动读取历史任务、轨迹或连续心率；不是已经取得上传授权。
