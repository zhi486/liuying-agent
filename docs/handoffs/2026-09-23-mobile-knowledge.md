# 手机端知识选择、剧透许可与来源展示

后续：用户已授权并完成[正式部署与手机覆盖安装](2026-09-23-knowledge-production-update.md)。下方未部署描述为本地开发批次历史，真实模型调用仍未执行。

## 本轮范围

用户明确要求接手机端知识库选择、剧透许可、来源展示，并继续实施。主代理直接实现，未用子代理。保留大量既有工作区修改，不提交或推送；未读取密钥、部署、调用真实模型或改真机。Workers 技能用于核对请求级状态、来源/任务边界与运行时验证；未改 DO 类、平台配置、绑定或兼容日期。

## 实现

- 首页增加不使用知识库（默认）、运动健康、流萤官方资料三项。只有角色库可选本次剧透，默认关闭；换库和发送成功后重置许可。不改变跑步、手环、语音或仅保存行为。
- `cloud.prepare` 可选 `knowledge`（固定版本、库、布尔剧透）；原生验证回显，前端逐字段核对。确认页再次展示，准备期间锁定输入，取消不发网。问题/记忆/选择改变会作废准备，篡改回显被拒绝并丢弃令牌。
- 独立授权版本 `selected_knowledge_v1`，Room v5→v6 只增可空 `knowledgeJson`。旧版本保持原义，旧任务不补空知识字段。选择与原请求同存，含记忆时仍事务核对版本/删除状态后领取唯一 POST 许可；重启/断流只查询不补发。
- 后端严格接受选择并冻结，服务将选择加入任务指纹，再从人工目录构建索引传给 Loop。相同请求键不能改变知识库或剧透。显式选择与宿主不匹配拒绝，不静默降级；未选择保持旧路径。
- Loop 为显式知识任务返回独立 `sources`，程序从实际命中生成，不解析模型正文链接。来源最多3条，带标题、官方地址、发布日期（未知 null）、核验日期和片段版本 ID。原直接调用可选知识接口的本地路径保持 Markdown 附录兼容。
- 原生/前端校验结构化来源，跟随完整答案持久保存；重载后展示，撤回时一起隐藏。来源地址是可选中复制纯文本，不放无效外链，不扩大现有 WebView 导航能力。说明明确不是逐句引用保证。正文中的任意 HTML/URL 仍是纯文本。
- 继续保留原有输入计数、预算保护和任务上限，不扩大计费工程；没有可用资料时不请求模型，正式运行配置门禁仍在。

## 上线边界与下一步

本轮只是代码及本地验收，生产云和真机均未更新。应先明确授权部署新后端，再覆盖安装APK，必要时私密配置供应商新密钥/费率，并另行允许一次真实回答；不能把模拟回答当成真实效果。旧服务会拒绝新字段，不应偷偷删掉知识选择重发。

当前语料仍只有WHO一份与流萤官网两份（其中一份剧透），资料有人工30天复核期限，没有自动刷新或完整剧情覆盖。检索词项命中不等于能回答整个问题，真实回答的引用/无依据行为仍待人工评测。来源没有点击外部浏览器功能。未新增云资源、日更或付费服务。
