## 数据与计数证据

合成短请求冷/热各 393；两段 2000/1999 UTF-16 code units 长输入分别 1683/1479；三轮为 407/481/572；断流 401、取消 397、撤回 397、截止 401、模拟网络失败 401。

云端调用实际私有计数器，对同一序列化请求计算 SHA-256。参考工具在本地用正式服务生成请求，再送入锁定 Python 参考；比较按 case、requestId、round、bodyHash 与 token 数，不混淆相同正文的冷/热新任务。云端没有输出完整 token IDs，本轮不能称为云 IDs 差分；此前本地完整 ID 差分仍是另一份证据。

独立 D1 回读逐任务关联：10 条任务、12 条预留/派发、8 份已应用收据。前六个完成任务共 8 条 settled，每份 1000/20 合成 usage，按合成费率记账 324 微美元，共 2592。取消、撤回、截止和模拟网络失败各一条 uncertain，每条保留 6720，共 26880；charged=null、无收据。金额不是实际 API 消费。

47 条脱敏 tail：33 入口、12 execute（含两次同键校验而零新计数）、2 interrupt。无解析错误或平台异常；唯一 canceled 为主动断流入口。客户端 35 次尝试比 D1 计数多 3：其中无效外层令牌明确不计门禁；另外两次缺少逐请求响应归档，不把差额擅自归因为 DNS 或其他具体原因。

## 性能边界

所有 CPU 均为平台 invocation 实测，包含测试 SHA、D1 观察写入及门禁，不是纯分词耗时。入口和 DO 分开核对，墙钟不能替代 CPU。

**人工断流入口 17 ms 高于普通 Free Worker 标称 10 ms。** 它包含额外轮询和未完成流；outcome=canceled 与主动断开一致，未见 exceededCpu。不能凭此归因 CPU 超限导致取消，也不能把它排除后笼统宣布所有入口性能通过。需后续在不含屏障的正式入口补一次小范围独立测量。

case 9 出现第三个实例标记，CPU 335 ms，说明热缓存不能被视为永远存活。首见标记不证明具体驱逐原因。DO 冷启动 CPU 是本轮事实，不等同于长时负载 SLA。

测试没有让手机飞行模式、改变 VPN/系统网络或杀 App。断流是运行中真实 socket 中断，但带人工观察屏障；云端实例崩溃恢复、长期运行、峰值内存和真实模型账单仍未验收。
