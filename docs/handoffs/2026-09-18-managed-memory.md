# 可管理的本机长期记忆：M3 首批

日期：2026-09-18。用户指示“先做可管理的长期记忆”；精细计费扩展继续暂停，不扩大云端或费用授权。本机管理首批已完成，未安装真实手机；不代表 M3 全部完成。

## 本批实现

- 首页新增“管理记忆”，进入 `/memories` 的“我的记忆”。用户可以显式新增、分页查看、编辑、确认删除偏好；显示手动来源与更新时间。
- 每条最多 500 个 UTF-16 单元；统一 JS/Kotlin 空白规范，保留中文与合法 emoji，拒绝空白及孤立代理字符。
- 原生 `agent/memory/MemoryCommands.kt`、`MemoryDao.kt`、`MemoryService.kt` 负责严格参数、事务和持久化。AppModule→MainActivity→WebPreviewHost→NativeWebBridge 接通，独立于跑步协调器与快照。
- AgentDatabase v3→v4 只增加 `agent_memories`；旧版 1/2 的迁移链继续支持，不销毁旧任务或云意图／回执。
- 创建 ID 支持重试；编辑携带原版本，过时版本拒绝。删除清空正文，仅留无正文标记，迟到创建和编辑不能使其复活。
- 前端校验结果内容、目标 ID 和版本后才报告成功；重复点击、迟到列表与断桥回包隔离；编辑器独立于列表，断桥／换页不会藏起未保存草稿。
- 同包协议新增 `memory.v1`，四个命令及共享夹具见 `contracts/v1/README.md`。

## 隐私与产品边界

仅保存在手机 noBackupFilesDir；不自动备份、不跨设备同步，卸载／清除数据可能丢失。数据库没有新增加密，不适合存密钥；清空正文不是 SQLite/WAL 历史字节安全擦除承诺。

本批不自动提取聊天、不上传、不调用模型、不使用记忆生成回答。首页“在线执行”仍未开放，RAG 尚未实现。用户保存偏好不等于授权云端使用它。现有跑步与语音行为没有在本批修改。
