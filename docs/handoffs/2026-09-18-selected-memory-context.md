# 本次记忆选择、原生核对与云端上下文

日期：2026-09-18。承接用户“继续下一步”，沿用 Cloudflare Agent 路线，不借用跑步陪伴 DeepSeek 开关，也没有新建手机直连模型栈。本批交付选择预览和后端记忆接入；不是完整手机在线回答闭环。

## 已完成

- 首页新增折叠的“选择本次记忆”，默认不读取列表、不选择。展开后从本机读取，最多选 5 条，每条仍最多 500 个 UTF-16 单元。
- `memory.preview` 只接收 ID/版本。Room 事务按顺序重读当前归属、手动来源、活动状态和版本，任一失效整次拒绝；不接收网页正文或授权，不复制保存记忆。
- 页面核对结果数量、顺序、ID、版本、正文及 `local_preview` 标记，显示“本机核对通过 · 尚未发送”。刷新、换页、收起和断桥清空选择；修改问题废弃预览；迟到结果不能恢复它。“仅保存”仍只有问题文字。
- 后端任务可选 `memoryContext: { version: "selected_memories_v1", approved: true, items: [{ id, version, content }] }`。严格唯一 ID、版本、数量、正文与独立授权校验，未知字段拒绝。首次 await 前深复制冻结，完整字段参与请求指纹；同键改记忆冲突，同键同内容不重发模型。
- 正式 HTTP→现有运行时→应用服务→Agent Loop 保留上下文。记忆作为独立 user 级资料，问题后置；仅带记忆时添加不可信资料说明。工具权限仍由代码控制，记忆不能自行扩大摘要范围或改变运动设置。
- 旧任务省略字段时，格式、规范化指纹和系统提示维持原样。没有额外数据库迁移，原生仍为 Room v4；跑步、语音、精细计费和云配置未改。

## 仍未完成的边界

本机选择／预览不等于上传授权；当前没有真实发网按钮或授权提交。`CloudTaskIntent` 仍为 `prompt_only_v1`，不能偷偷扩展含义，不能把记忆拼入 prompt 绕过授权。S5 仍需设备私密配置、原生在线 Bridge/DI、单次确认与版本复核、结果展示和恢复控制。

后端接收已认证客户端提交的授权声明，不能独立证明屏幕点击或记忆的本机真实性。提供给模型的记忆不等于每条被模型采用；当前结果没有结构化使用回执。模型提示不能保证抵抗所有文本干扰，但工具权限不会由资料文字改变。

结果文本可能引用记忆，仍适用已有确认、撤回和保留期；本机删除不能追溯撤回已经发给供应商的数据。S5 发送前必须重新读取并确认最新 ID/版本、明确展示问题与记忆；不得缓存预览后直接发送。RAG、自动提取、长期云同步未实现。
