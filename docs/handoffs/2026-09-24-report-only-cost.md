# 费用只估算与记账，不按预算停用

2026-09-25 更新：已随 Fun-ASR 配套版本完成真机安装和正式后端发布，见[发布交接](2026-09-25-fun-asr-production.md)。下文未安装／未部署描述属于此前历史。

日期：2026-09-24。用户要求：展示成本估计值、记账；预算超出不要关闭功能。此要求优先于此前每月 $2 硬门槛，开发重点仍是长期记忆与 RAG。

## 实现范围

- 取消新请求／实际派发中的月金额、历史 halted 标记及费率过期门槛。旧数据库字段保留，但不再影响执行；不需要迁移。
- 用量、原费率快照、估算微美元仍持久记账。超预留或冲突收据只标记异常，不再停用账户；首条收据、防重复派发、取消、设备撤销及原请求截止保留。
- 结构正确的旧费率继续估算并标为 stale；缺失／无效／未来费率使用已核验参考价（reference，输入 $0.30/M、输出 $1.20/M），不会伪装成实时价。不联网刷新、不延长旧时间戳。
- 结果新增可选 cost，包含费用、输入／输出 token、用量完整性和费率状态。手机原生验证／持久化／列表与网页展示已接通；无费用旧回执兼容，未知费用显示待确认而非零。
- 展示的是结果保存时快照；后到收据可以修正账本，但不会自动改写旧回答快照。不是供应商发票，不包含缓存／离峰折扣，也不是全 App（含 Fish／Cloudflare）的总账。
- 不取消 3 步 Loop、输入／输出大小、30 秒截止、鉴权和单次授权。账本不可用仍不能冒险派发，避免丢失去重依据；单独读取估算失败不会丢弃回答。
