# 共享返回控件

正式页面使用 `BackLink` 或 `BackButton`，统一从 `BackControl.tsx` 导入，不在业务页面重画箭头或圆形边框。

- 路由返回使用 `BackLink`，保留原有入口感知返回目标；抽屉内部状态切换使用 `BackButton`，保留原回调及焦点归还。
- 外观统一在 `BackControl.module.css` 修改。大小使用 `tokens.css` 中的 `--back-control-size` 和 `--back-icon-size`；触控区至少 44px。
- 深色跑步页传入 `inverse`，沿用跑步页背景和青绿色。普通页面使用当前主题变量。
- 页面外壳负责安全区和滚动容器；普通子页沿用 `AppLayout` 的 sticky 导航。抽屉内需要吸附时使用 `sticky`，不要叠加另一层 fixed 外壳。
- `label` 同时提供可访问名称与悬停提示，准确说明返回目标。关闭弹窗、取消操作及停止生成属于其他动作，不替换为返回按钮。
- 组件设计台的 A/B/C 对比样本保留各自方案；其正式“返回应用”入口仍使用共享组件。

修改后检查 `back-navigation.spec.ts` 和 `sticky-back.spec.ts`，并查看日夜主题、320px、大字体与跑步页截图。导航测试会修改同一个尺寸变量，确认抽屉、子页及跑步页同步生效。

## 共享交互动效

- 正式页面的复选框和开关统一使用 `ChoiceInput`，保留原生 input、标签、焦点、禁用及原回调。开关通过 `variant="switch"` 使用；既有 checkbox／switch 角色保持不变。勾选不代替提交授权，异步开关不提前宣称保存成功。
- `MenuGlyph` 使用同一组三条线响应侧栏状态，上下旋转、中线收起。聊天入口与抽屉关闭共用 body Portal 内的同一个按钮，保留原位占位；不隐藏原图标，也不挂载第二个叉号。打开后按钮与面板一起纳入模态焦点范围，关闭后焦点留在原按钮。
- 开关滑块先横向拉伸，再压缩回弹，380ms 内稳定。只在用户交互后的真实选中值改变时播放；异步等待、失败或初次读入不预演成功。轨道、触控区与文本均不随形变改尺寸。
- `AppLayout` 只装配一次 `useButtonRipples`，事件委托覆盖普通页面和 body Portal。波纹从真实指针位置扩散，键盘从中心扩散；不拦截事件、不调用业务命令。松开、取消、失焦和卸载均清理，单个按钮最多一层，定时兜底防止残留。顶栏新建加号保留按下波纹；其固定槽位先于波纹建立定位上下文，波纹插入时图标坐标不变。页面圆形揭示由独立 View Transition 承担，两者互不改写布局。
- 时长、控件尺寸和圆角统一在 `tokens.css` 管理，绘制和弹性形变集中在 `interactions.css`。填充式图标无法按路径描画，因此勾选使用单根归一化中心线；其他图标继续用既有 Phosphor 系统。
- 系统减少动态效果与 App 的 reduced／off 均尊重，移除空间形变与波纹，保留准确的最终状态。初次读取已选状态不播放勾选／弹性入场。
- 组件参考台 A/B/C 是历史方案对比，不自动替换样本。正式页面的所有复选框均已接入共享控件。

改动后运行 `Interactions.test.tsx` 和 `interaction-motion.spec.ts`，并回归授权、插件选择、导航及跑步页。动效中间帧使用合成 Bridge 截图，不触发真实权限、模型、插件或语音。

## 圆角分类与授权控件

圆角采用“底层尺度 → 语义角色 → 页面视觉覆盖”三层结构。业务 CSS 只能引用语义角色，不得直接使用 `--radius-scale-*`，也不在页面里另造圆角变量。设计台方案对比样本不受正式页面门禁约束，但新接入的正式页面必须遵守。

| 类别     | 令牌                                                   | 用途                                                               |
| -------- | ------------------------------------------------------ | ------------------------------------------------------------------ |
| 输入     | `--radius-input`                                       | 文本输入框、搜索框、重命名框、聊天 textarea、下拉框                |
| 操作     | `--radius-button`                                      | 同页普通文字按钮、图标操作按钮；圆形图标按钮改用 `--radius-circle` |
| 行       | `--radius-row`                                         | 会话列表、任务列表等整行可点击项                                   |
| 小表面   | `--radius-compact-surface`、`--radius-control-surface` | 上下文胶囊、语音提示、读数卡、图表内小面板                         |
| 内容表面 | `--radius-tile`、`--radius-card`、`--radius-panel`     | 图标底板、普通卡片、页面主面板和输入舱                             |
| 提示     | `--radius-notice`                                      | 状态、错误、空态及短说明块                                         |
| 弹层     | `--radius-drawer`、`--radius-dialog`、`--radius-sheet` | 侧栏、对话框、底部 Sheet                                           |
| 消息     | `--radius-message`、`--radius-message-tail`            | 聊天气泡及尾角                                                     |
| 特殊形状 | `--radius-choice`、`--radius-pill`、`--radius-circle`  | 复选框、胶囊、圆形                                                 |
| 方角     | `--radius-none`                                        | 全出血页、分段连接边及明确不设圆角的结构                           |

同一页面里的同类组件必须使用同一个语义令牌；页面需要气质差异时只覆盖该页面的语义映射，不改变单个控件的数值。选择分类时先判断组件职责，再判断元素标签，例如整行对话按钮使用 `--radius-row`，普通命令按钮使用 `--radius-button`。`RadiusTokens.test.ts` 会拒绝对底层尺度、旧别名和裸数值的直接引用。

- 持续聊天授权、自动记忆、事实写入使用 `AuthorizationSwitch`。授权前保留独立的同意勾选，开关等原生回执确认后才改变状态；关闭不要求勾选。单次确认、筛选、视图切换与执行命令不做成开关。

## 统一页面过渡

- `AppLayout` 通过 `usePageTransition` 装配 B「层级」方案：进入子页从右侧 24px 淡入，240ms；返回上级从左侧 24px 淡入，200ms；同级切换仅淡入，180ms。
- 聊天与跑步使用固定视口，因此进入这两页只淡入，不对其主内容做 transform，避免影响内部固定定位、键盘高度及已有抽屉推移。
- 返回按钮与页头不参与位移；仅动画当前主内容，不复制旧页面、不延迟业务挂载、不改变返回目标和授权状态。同页刷新状态不重复播放；快速导航、卸载与动态效果策略变化立即取消旧动画。
- 系统减少动态效果及 App reduced 仅保留 100ms 淡入；off 完全不播放。Web Animations API 不可用时正常导航，不以动效阻塞功能。
- 时长、距离与缓动仍集中在 `tokens.css`。验收覆盖 `usePageTransition.test.tsx`、`AppLayout.test.tsx`、`interaction-motion.spec.ts` 及返回导航、跑步准备页回归。
