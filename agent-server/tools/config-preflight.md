# 私密配置与费率预检

此工具仅本地检查，不请求 DeepSeek／Cloudflare，不部署、不签发设备凭据、不写文件，也不更新价格或时间。2026-09-23 起费率检查仅诊断估算质量，不是执行门槛：运行时允许旧费率，缺失或无效时采用带明确标记的参考价。预算超出不关闭功能；认证、取消、设备撤销、截止及防重复派发保护仍有效。

## 输入与执行

当前开发测试全部使用合成数据，暂不需要填写真实密钥。需要正式配置时再经授权准备；不要把密钥发到聊天、命令参数、环境变量设置命令或终端交互粘贴区。

空模板是 `tools/config-preflight.example.json`。用户可在本地编辑器将其另存到尚不存在的 `secrets/agent-runtime.json`，不要修改已跟踪模板或覆盖已有私密配置。`secrets/` 已被 Git 忽略，但这不是磁盘加密、备份隔离或访问权限保证；不要上传该目录，避免同步到公共位置。密钥使用新配置，不复用曾在聊天公开的值。

JSON 根对象只允许以下两项：

| 字段 | 内容 |
| --- | --- |
| `DEEPSEEK_API_KEY` | 用户私密填写的密钥字符串；工具仅判断格式，不认证 |
| `RATE_CARD_JSON` | **字符串**，内容是下表六字段 JSON；不能直接填嵌套对象 |

在 `agent-server` 目录执行，文件内容通过管道传入，不在终端打印：

```powershell
Get-Content -LiteralPath 'secrets/agent-runtime.json' -Raw -Encoding utf8 | corepack pnpm preflight:config --stdin
```

只看帮助：`corepack pnpm preflight:config --help`。工具不自动读取环境变量、`.env`、`.dev.vars` 或其他私密文件。无参数、未知参数或 TTY 交互输入均拒绝；封装上限 16 KiB 原始字节、严格 UTF-8，读取设置 5 秒截止。它不是保证操作系统调度下的精确 5 秒 SLA。

退出码：`0` 本地格式/有效期通过；`1` 密钥或费率检查未通过；`2` 参数、JSON 封装、输入流、编码、体积或超时错误。所有输出为固定状态，不展示密钥前后缀、摘要、版本、价格、时间或原始异常。

## 费率内容与核验流程

| 字段 | 规则 |
| --- | --- |
| `version` | 本次核验标识，1–80 个英文字母、数字、下划线或连字符 |
| `model` | 仅 `deepseek-flash`，不是任意可切换模型 |
| `inputMicrosPerMillion` | 每百万输入 token 的整数微美元单价，正安全整数 |
| `outputMicrosPerMillion` | 每百万输出 token 的整数微美元单价，正安全整数 |
| `checkedAtMillis` | 实际人工核验时间，非负安全整数的 Unix 毫秒值 |
| `expiresAtMillis` | 大于核验时间、最多相差 86,400,000 ms；当前时刻必须严格早于此值 |

`RATE_CARD_JSON` 字符串最多 2048 code units，预检不自动修复输入。运行时保留结构正确的旧费率；缺失、格式非法或未来时间改用 `reference_deepseek_flash_20260923` 参考价，并明确展示参考状态。预检时间来自本机当前时钟，CLI 不提供伪造检查时间参数。

人工先核对 [DeepSeek 官方价格页](https://api-docs.deepseek.com/quick_start/pricing) 的模型别名/版本、币种、计价单位、缓存命中/未命中和峰谷规则，再形成独立核验记录。当前账本只有输入/输出两个费率，应采用经核验的保守上界；不能将其展示为包含缓存/离峰折扣的供应商精确账单。本工具不内置现价，也不能证明填写者真的完成核验。

模型别名或版本变化时，还须确认锁定 tokenizer 的适用性与获准真实 usage 对照；预检通过不是 tokenizer 的在线计费认证。

价格到期仅影响估算标签，不停止新任务。旧键查询、取消、撤回、维护及原费率快照结算继续有效。刷新时必须重新核验，不得只把旧价格的时间戳向后移；自动价格更新不在本批范围。

## 预检不等于部署

预检成功仅表示本地格式和有效期检查通过，不证明密钥真实有效、余额充足、官网价格一致、远端 Secret 已安装、D1/DO 配置正确或网络畅通。退出码 1 可能仅表示费率需要更新，并不代表运行时必须拒绝任务；不再提供每月 $2 硬封顶。

真正安装前单独确认 Worker／账户／D1 目标、迁移版本和调用预算；不使用验收 `session.json` 或旧隔离资源当正式身份。密钥只使用私密 Secret 渠道，不进入 vars、源码、APK、网页、日志或交接。

[Cloudflare 官方 Secret 文档](https://developers.cloudflare.com/workers/configuration/secrets/)说明 `wrangler secret put/delete` 会创建版本并立即部署。`versions secret` 虽可仅创建版本，仍是远程写入，也需要单独授权。本工具不会调用这些命令，更不会替用户同意部署。

## 设备管理操作边界

现有 `createDeviceAdmin` 已支持可信发放/撤销，普通设备 Bearer 没有管理权限。本批只记录流程，不新增公开管理接口或执行真实操作：

1. 明确目标 D1 与唯一 owner；复用现有账本，换机不清零用量记录。历史额度／熔断字段不再决定是否接单。
2. 手机 Keystore 和安全导入完成后，经批准由可信管理端发放 90 天凭据；D1 仅保存摘要，原值一次性私密交付，不打印到日志或保存成验收产物。
3. 换机显式决定是否撤销旧设备。撤销先持久落库并取消该设备未终结任务；已经可能派发的费用保留，不能保证瞬时停止远程计算。
4. 只保存非秘密管理证据，例如目标、设备 ID、到期/撤销时间与操作结果。真实操作后分别验证新凭据可用、旧凭据被拒绝；本轮没有做这些验证。
