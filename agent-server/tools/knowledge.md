# 精选知识库：本地首批

手机选择、原生授权/持久化、正式服务检索和来源展示已在代码中接通，尚未部署或安装真机，不代表线上已经启用 RAG。没有嵌入、向量服务、爬虫或定时刷新，不新增模型工具。详见[手机知识接线](../../docs/handoffs/2026-09-23-mobile-knowledge.md)。

## 演示

2026-10-30 已重新只读访问 WHO 原页和官方角色 CMS 的中文／英文单条记录，核对现有摘要，正文无需调整。三条资料升为 v2，复核时间 2026-10-30T01:34:49Z，人工复核期限 2026-11-29T01:34:49Z；发布日期和剧透分类不变。当前服务端支持按需 knowledge.search，闲聊不强制检索；未部署或真实模型验收。详情见[本次复核](../../docs/handoffs/2026-10-30-knowledge-reverification.md)，下文 9 月记录为初次收录历史。

在 `agent-server` 目录运行（不联网、不调用模型、不读取私密配置）：

```powershell
node --experimental-strip-types tools/knowledge-demo.ts health "步行和久坐"
node --experimental-strip-types tools/knowledge-demo.ts firefly "流萤是谁"
```

两条在资料有效期内分别返回 WHO 摘要与流萤基础介绍及来源。演示只展示检索，不把假模型文本冒充真实回答。`src/knowledge-corpus.ts` 当前有三份人工中文摘要：WHO 身体活动一份、流萤基础介绍一份、含剧透身份身世一份。默认演示不允许剧透，查询“萨姆”返回 `no_match`；可信宿主显式传入 `allowSpoilers: true` 后才可检索身份身世。

来源：[WHO Physical activity](https://www.who.int/news-room/fact-sheets/detail/physical-activity)，页面日期 2024-06-26，本次实际访问核验 2026-09-23。摘要只覆盖身体活动范围、避免完全不活动和减少久坐的原则，不提供个性化训练或疾病诊断。30 天复核期限为本项目人工维护策略，并非 WHO 的医学有效期。到期须重新阅读来源，不得只延后时间戳。

流萤来源：[星穹铁道官网角色页](https://hsr.hoyoverse.com/zh-tw/character)。2026-09-23 已通过该页面脚本引用的公开 CMS 接口读取角色 123957 的中文正文，并核对英文名。基础资料限于名字及萤火意象；身份、装甲、身世与动机单列为剧透。没有导入玩家百科、攻略、配音音频或未核实的技能/剧情。官网没有清晰的文章发布日期，故使用 null，不将 CMS 上线日期或创建日期冒充发布日期。30 天人工复核，到期不自动续期。

公开取证路径、字段映射与更新步骤见[官方语料交接](../../docs/handoffs/2026-09-23-official-knowledge-corpus.md)。这只是官网基础介绍的首批覆盖，不是完整剧情库。测试中的虚构夹具不能并入生产语料。手机已有单次剧透复选框；日更、自动发现、更多剧透层级、自动冲突判定尚未实现。

## 数据与边界

- `createKnowledgeIndex` 只接收可信人工目录：最多 100 份、每份正文 8000 个 UTF-16 单元，总正文 64000。每份有唯一 ID、库、标题、HTTPS 来源、版本、发布时间（未知为 null）、核验时间、期限、撤回与剧透标记。
- 当前来源主机白名单分别为 `www.who.int`、`hsr.hoyoverse.com`，拒绝凭据、查询参数、非标准端口、错库主机和伪子域。白名单不是事实核实：每条仍须人工检查官方原文、路径、摘要、日期和使用范围。
- 按空行分段，超过 480 个 Unicode 字符的段切片，最多返回 3 段。中文双字词项／英文单词匹配，稳定排序，无语义嵌入或同义词扩展；跨切片词语可能漏检，常见词也可能误命中，需后续固定题集评估。
- 每次检索按所选库、有效期、撤回和剧透设置过滤；没有匹配与没有可用资料是不同状态。索引是不可变快照，资料更新／撤回须重建并替换索引。已开始任务持有原快照；生成结束时再次检查过期，但不保证正在生成时动态撤回。
- 不保留查询，不读记忆全库，不请求来源 URL。文档正文没有执行能力。

## 接入 Agent Loop

可信宿主可向 `runAgent` 的第三个参数提供 `knowledge: { index, library, allowSpoilers? }`。HTTP 任务现在可选 `knowledge: { version: "curated_knowledge_v1", library: "health" | "firefly", allowSpoilers: boolean }`；健康库拒绝 true，不能传任意索引、URL 或正文。省略字段保持旧请求指纹，选择会随规范化任务一起哈希；同键换库/剧透冲突。正式服务由本地人工目录建索引，显式任务选择缺失或与宿主不一致时拒绝，不静默无资料执行。手机确认页再次展示选择，默认不使用库、不允许剧透。

检索结果以 `curated_knowledge_v1` 用户级资料放在问题前，与 `selected_memories_v1` 分开；system 只添加固定使用规则，不包含资料正文。无结果不预留额度、不调用模型，但仍检查任务授权和取消。正常结果保留既有模型／工具上限、输入计数和费用结算；不增加专用模型检索轮次。

显式手机任务的 completed 结果独立携带 `sources`（至多3条），字段为 `citationId/title/url/publishedAt/checkedAtMillis`，由检索命中生成而非模型输出。无结果为 `sources: []`，不冒充引用。手机将来源与答案一起保存，显示标题、可选中复制地址、日期和片段版本标识；不自动打开外站，不把模型正文链接当可信来源。撤回同时隐藏答案及来源。未选择知识的旧结果不补字段；原直接传宿主选项的本地调用保留 Markdown 来源附录。答案仍受4000字符限制，来源另有数量/字段上限；过期或超长不交付、不自动重试。

这些约束不能证明模型每一句都由资料支持，也不能阻止模型在正文自行输出未核实网址；尚无逐句引用验证或事实判定。上线前仍需要真实回答评测。角色资料不应作为健康建议依据；库隔离在代码中实现，模型对混合问题的遵守程度仍需评测。
