## 可重复运行

### 文件库跨进程边界补测

`MemoryProcessRecoveryTest` 使用专用 Room 文件库及独立授权文件，不使用本机真实配置。仅在隔离模拟器运行；同一 `memoryCaseId`（新 UUID）先启动 `memoryPhase=seed`，外部终止应用进程，再以 `memoryPhase=recover` 启动第二次 instrumentation。`memoryScenario` 可为 `saved`（默认）、`deleted`、`revoked`、`reenabled`；每个场景必须换新 UUID，不能复用上一次测试数据。恢复阶段在 Android 内核对实际 PID 不同，不把 instrumentation 结束后查不到 PID 视为失败。

删除场景通过正式管理接口更正后确认删除，验证两个历史正文指纹均持久化；撤权及重开场景通过正式授权接口变更代次。第二进程核对原调用 ID、新调用 ID 和搜索的边界，仅显式恢复原任务，不重新提交；拒绝结果回传后再次恢复不重复工具回传或记忆写入。此测试的 `CloudTaskApi` 为进程内合成实现，计数不是 HTTP 请求；不能代替下述 HTTPS 联合测试、真实模型决策或用户手机断网验收。

先用项目 `build:worker`（`wrangler deploy --dry-run`）重建当前 `.generated/bundle`，不能沿用旧代码产物；再构建当前应用及设备测试 APK，并仅将隔离签名副本安装到专用模拟器。模拟器必须为 `ro.kernel.qemu=1`、飞行模式开启、Wi-Fi 关闭且无外部路由。随后从 `agent-server` 执行：

```text
pnpm test:native-memory emulator-5580
```

工具拒绝真实手机序列号；每次生成独立短期证书，原生只信任该证书且保留正常主机名验证。不安装系统 CA，不加载真实私密配置或远程绑定。临时 HTTPS 只监听 `127.0.0.1`；通过本轮 adb reverse 接入，结束释放该端口。Miniflare 出网只接受确定性模型替身，其他外部访问失败。临时文件和成功／失败证据均保留在 `.generated/native-memory-*/`。

## 当前七项验收

| 场景 | 真实链路检查 |
| --- | --- |
| 保存、跨会话搜索、更正、删除 | 四个独立会话都不夹带旧消息或手选记忆；模型经工具保存、读回本机记录，更正沿用 ID、版本 1→2；旧版本上下文失效，正式本机管理删除后检索为空 |
| 撤销后重新开启 | HTTPS 工具响应已取回但未交原生时设置屏障；经正式原生命令关闭、重开，代际改变；原任务得到 `consent_required`，Room 无写入，恢复不复活授权 |
| 保存回执 ACK 丢失 | Room 保存和正式云端消费后真实关闭 TCP；原生保留待确认错误，显式恢复取得原答案，不重发问题或记忆结果，记录保持原 ID／版本 |
| 自然消息附带问题 | 从“我更喜欢晚上跑步，你能帮我安排吗？”保存完整声明；新会话无旧消息夹带，正式工具检索返回原句 |
| 否定偏好 | “我不喜欢太长的回答”原样保存，不能丢失否定；新会话正式工具检索返回原句 |
| 同消息拒绝保存 | “我喜欢夜跑，别帮我保存下来”即使模型请求写入也得到 `evidence_required`；Room 零写入、恢复不绕过 |
| 手工历史删除与明确重记 | 经正式管理创建／更正且无 Agent 回执，在工具响应屏障中删除；迟到旧正文与普通重述均返回 `conflict`，只有删除后明确新“请记住：”才新建记录，新会话正式搜索命中；旧正文／历史不恢复，恢复查询不重复保存 |

模型只根据收到的正式原生工具观察决定下一步；不以 JS 直接代替手机读写或伪造保存结果。脚本独立核对 D1 完成任务数、模型轮数、工具回传、最终答案确认次数，以及恢复前后的提交／回传计数。首次恢复可以确认未收到的最终答案，此后不能重复确认。

第三十二批两轮均为三个真实成功、零跳过：`native-memory-sgfYDU/`、`native-memory-GHxIGu/`。每轮六个完成任务、七次工具回传；生命周期的四个任务模型轮数为 2／2／3／2，另两项各两轮。另有 38 项设备原有记忆回归、38 项 JVM／七套件、10 项 workerd／两文件，以及 Node／Workers 两套 TS 检查通过。初轮测试漏切旧会话导致正式预览被正确拒绝，失败证据 `native-memory-zYVKOS/` 保留；已修正测试，不改生产会话校验。

第三十三批最终六项通过，证据 `.generated/native-memory-E0yC9v/`：11 个完成任务、12 次工具回传、23 次合成模型请求，零跳过。原有设备回归 38 项、记忆 JVM 40 项、全量 JVM 1,077 项／115 套件、定向 Node 23 项、workerd 10 项及双套 TS 通过。较早 `native-memory-D4y2GZ/` 尚未扩展自然／否定偏好的新会话检索，不算相同版本的重复验收。首轮旧实现的预期 JVM 失败另存 `output/memory-batch33-red-jvm-20261018/`；修改后报告在 `output/memory-batch33-{jvm,full-jvm}-20261018/`。未重跑完整 Node／workerd／前端，既有 BPE 失败未解决。

## 尚未证明的能力

- 当前保存策略只允许当前消息中完整、确定的第一人称偏好／目标声明分句，可与其他请求共存；须原样保留否定与修饰，不支持任意子串抽取或改写。整条消息的已知引用／假设／过去／转折／拒绝保存语境保守拒绝；这不是通用语义或隐私分类器，可能误拒绝合法表达。仍不支持任意总结记忆文档、敏感事实或资料指令，合成模型不证明真实模型一定正确选择工具。
- TCP 故障是本地真实断流，不等于手机整机断网、移动网络抖动、云端驱逐或公网时延已验收；既有跨进程模拟测试不冒充本批 HTTPS 进程恢复。
- 记忆权威库仍在本机；本批 Room 为隔离内存库，测试身份和授权均为虚构，不改变实际用户权限。
- 未发布、迁移正式数据库、安装手机、触发真实模型／语音／插件或提交 Git。前端未改，无新增 UI 或截图验收。
