## 方向与边界

- 官方 MCP SDK 仍在服务端；手机只负责受限 HTTPS、私密凭据读取以及 JSON／SSE 终止信封解析，不再实现一套 MCP 客户端。
- 可信宿主按已认证账号／原设备、原操作、服务目录版本及本机配置代次创建通道。工具执行另需原任务和批准绑定；发现是独立配置操作，不要求目录已启用。请求中的标识用于匹配，不是授权；模型不能创建这些绑定或提供网络请求。
- 下行固定字段为 `version / requestId / taskId / serviceId / revision / generation / endpoint / exchangeId / method / body / sessionId / protocolVersion`。仅转交 SDK 的 `POST` 和会话结束 `DELETE`；首版不监听独立通知 GET，云端本地返回 405，不发往手机。
- 成功回执只含 `version / exchangeId / generation / status / text / sessionId`。JSON 与 SSE 均归一为单个 JSON-RPC 终止响应；202、204、405 正文为空。失败回执只含前三个标识及固定 `error`，没有任意异常正文、URL、重定向或响应头通路。
- 插件 Bearer 只由手机当前加密配置读取并加在手机到插件的请求上，不随协议上传，不复用云设备凭据。

## 时限与断网

- 一会话最多 13 次待发交换、总时限 10 秒；单个 POST 正文 16 KiB、回执正文 128 KiB、累计回执 256 KiB，JSON 嵌套在手机解析前受限。
- `take` 是一次性交付，不是普通可重试 GET。发现 HTTP 入口与手机客户端均使用认证、无缓存、不可重放的 POST，禁止自动重试。同一请求不会因为回执缺失再交付。
- 相同结果的重复回执可确认，冲突结果拒绝。手机同一通道实例拒绝重复交换和并发网络交换；关闭、取消、撤权、配置换代或过期不能复活。
- 云端内存通道及手机实例均不持久恢复请求正文；最终宿主必须结合已有派发账本收敛未知结果，不能重建实例后重跑旧 SDK／旧工具调用。已发送外部副作用无法靠本地撤权撤销。

## 独立发现操作 HTTP（2026-10-18，本地未发布）

路径前缀为 `/v1/agent/mcp/discoveries`，均使用既有设备认证。POST 集合只接收 `{ requestId, serviceId, revision, generation }`；端点从 D1 读取，不接受自报身份、密钥或目录。早回执 202 返回 `{ discovery }`，`GET /:requestId` 只查询原操作；`POST /:requestId/take` 必须无正文，返回 `{ exchange }` 或 null；`POST /:requestId/reply` 接固定回执，返回 `{ accepted: true }`。请求不能自动重发；相同 start 仅核对原操作，改变绑定返回冲突。

这里的 requestId 是配置操作标识，信封 taskId 同样设为该标识，不是聊天 task ID，不创建模型任务或派发工具调用。DO 在启动 SDK 前保存标识、原设备和输入摘要、固定视图，最多保留 64 个未过期配置操作；只在新建时清理超过 24 小时的内部元数据，不驱逐未过期去重标记。该限制防止无界状态，不是计费预算。重建后仍为 running 的记录改为 unconfirmed／interrupted，只查询、不重新启动 SDK。这里没有持久化密钥、请求／回执正文或 MCP 会话 ID，也不承诺外部“恰好一次”。

每次发送、领取及回执在 D1 重新核对原有效设备、服务 revision 和端点；传输期间的只读状态查询同样重核，供手机在发送前后检查。SDK 收尾后没有后续出网，目录条件提交可能更新 revision，此时查询只观察操作状态，不把自己的提交误判为撤权。SDK 完整 RPC 由请求的 waitUntil 持有，原 10 秒总时限不续租。配置变更、撤权或迟到回执不能覆盖新目录；发现完成的新目录默认关闭，完全相同的已有目录保留原批准，变更则清空批准。失败发现可能按既有存储规则使旧目录失效；unconfirmed 不是“元数据一定没变化”，应刷新服务详情核对。

## 原生发现同步（2026-10-18，更新至第二十二批）

`McpDiscoveryService` 已注册到应用依赖注入，复用 `CloudTaskHttpClient` 的设备认证与四个固定路由。可信宿主从当前身份和本机加密配置读取端点、配置代次及状态指纹，再建立独立操作绑定，不照抄下行请求作为授权。一次显式发现只有一个 start；整个同步最多 10 秒，取消向网络层传播，领取／回执失败不自动重试。仅空领取后的只读状态等待会继续查询。

每次插件发送前后都检查当前身份、本机配置和云端状态；发现同步只允许初始化、初始化通知、取消通知、工具目录与会话关闭，不能夹带 `tools/call`。仅手机到插件的请求读取插件 Bearer。回云结果采用固定字段／错误枚举、正文及会话 ID 限制，不能携带任意响应头或异常正文。

`McpDiscoveryJournal` 已在 start 前保存唯一绑定，按云服务／账号／设备／凭据代次的摘要隔离，AtomicFile 放在 noBackup 目录。每个身份最多 64 条、文件上限 512 KiB；容量满时仅移除最早已收到云终态的内部状态缓存，尚无回执或仍 running 的标识不能被驱逐，无法容纳则拒绝新建。它不是聊天记录、工具派发账本或任务队列，不存请求／插件响应正文、秘密或 MCP 会话 ID。

固定视图必须与原绑定和原时窗匹配，已确认的终态不可倒退或更换结果；同一视图不重复写文件。损坏、跨身份复制、未知字段或写入读回失败均关闭，不把文件错误当空历史或继续发网。文件原子写入测试不等于断电持久性保证。

`operations()` 只读取当前身份的本机记录，视图代表上次确认。`recover(requestId)` 只对本机原标识发一次状态 GET，不创建交换器、不访问插件配置／密钥、不重新启动 SDK，也不领取或回传交换。恢复不延长云时限，不需要插件凭据仍有效，但仍要求原云设备身份有效；身份换代不能接管记录，查询期间换身份的迟到结果不会写入。取消／网络失败／404 均保留原记录与上次状态，不推断未执行，不发第二个 start。第二十三批已通过独立 MCP 设置页暴露本机记录与显式恢复入口，管理操作总时限 8 秒以留出 Bridge 返回余量，不改变云端的原时限。

### 第二十八批前台任务交换（2026-10-18，本地未发布）

`McpTaskRunner` 已接首次发送调度、依赖注入及前台／Web 文档生命周期。恢复原任务不启动交换器。原任务、原回执、云目录及本机配置必须匹配；每次出网前后重新核验，插件密钥只在实际手机请求边界读取。空取件等待 100ms；同 SDK 会话共用十秒、最多十三次交换及累计 256 KiB 回执，不因握手、轮询或确认延长原三十秒任务。后台或重载使旧窗口代际失效，回到前台不补发。结束只尝试一次有界云 close，失败不重试。

### 第二十六批任务执行通道（2026-10-18，本地未发布）

正式提交新增可选 `mcpTools: {version:"native_mcp_v1",services:[{serviceId,revision,generation}]}`。最多 8 个不重复服务且必须存在会话，拒绝额外字段和密钥；服务列表按本次输入顺序进入原任务指纹，不能用同一请求键更换绑定。旧任务省略该字段，不自动启用账户下全部插件。实际目录／授权从 D1 读取，本机代际仍须 Android 从私密配置核验，不能照抄下行信封为许可。

Worker／DO 现已注入模型工厂；以下路由均使用既有设备认证，限定正式云 taskId 与原手机，并返回 no-store：

| 路由（`/v1/agent/tasks/:taskId/mcp`） | 请求与返回 |
| --- | --- |
| GET 本路径 | 无正文，`{confirmation: intent或null}`；只读，不交付交换 |
| POST `/take` | 空正文，`{delivery:{exchange,intent}或null}`；exchange 为既有 native_mcp_v1 信封，只交付一次 |
| POST `/reply` | 既有严格成功／失败信封，返回 `{accepted:true}`；不会因为回执丢失重派请求 |
| POST `/decision` | `{version,invocationId,intentDigest,generation,decision:"approve"或"deny"}`；返回 `{decision:{invocationId,status}}`，不接收 confirmed 布尔授权 |
| POST `/close` | 空正文，返回 `{accepted:true}`，关闭本次插件窗口，不自动取消聊天或重新打开窗口 |

`intent` 固定包含 `version / requestId / taskId / serviceId / revision / generation / endpoint / invocationId / intentDigest / argumentsDigest / modelName / name / mode / argumentsJson / expiresAtMillis`。它来自可信账本和批准快照；确认必须展示真实工具及完整参数，不能只显示摘要。take 的意图与交换一起交付，供手机复核工具调用正文，不能赋予手机新的服务范围或读取秘密的权力。确认只匹配当前待确认对象；迟到或重复确认可返回冲突／inactive，不能据此重发工具。配置发现路由仍不允许 `tools/call`，不是执行通道的替代品。

每次交付／回执／决策重新核对原任务和设备、服务版本及批准；原 30 秒任务截止不续租，单次 SDK 交换会话仍最多 10 秒。关闭会停止在途与等待确认，最后结果已到达但 SDK 尚未收尾时关闭也不将内容送下一轮；未知状态只作未确认说明，不换 ID 重做插件。服务版本在提交前失效时保存明确未执行终态，不调用模型。只把瞬时参数／结果留在内存，账本仍保存摘要；完成后优雅重建查询原任务不重跑 SDK。
